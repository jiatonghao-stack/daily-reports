# 📖 每日 AI 圈早报 · 云端关机运行与本地同步指南

这套系统专为**“哪怕电脑关机，每天早上 8:30 也能准时看到前一天 AI 圈 Top 20 总结报告”**而设计：

- **云端定时生成（不依赖本机开机）**：每天早上 **07:48（北京时间）** 由 GitHub 云端服务器自动启动抓取与大模型总结，**08:05 左右**即可将当天的 `YYYY-MM-DD-AI早报.md` 和 `最新早报.md` 写入仓库，确保 **08:30** 前准时就绪。
- **双端随时查阅**：
  - **电脑开机时**：本机自动同步服务会在你**打开电脑的瞬间**（以及开机期间每 10 分钟）静默把云端最新生成的早报拉取到 **`文稿/每日报告/`** 文件夹中，8:30 直接打开文件夹即可阅读。
  - **电脑关机时**：直接用手机或任何设备打开你的 GitHub 仓库页面，点击 `最新早报.md` 即可在线阅读排版精美的报告。

---

## 🚀 只需 3 步激活云端定时任务（一次性配置，永久自动运行）

### 第 1 步：在 GitHub 创建一个新仓库
1. 打开 [https://github.com/new](https://github.com/new) 登录你的 GitHub 账号。
2. 仓库名填例如 `ai-daily-report`（建议选 **Public** 公开仓库，GitHub Actions 免费无限分钟数；Private 私有仓库每月也有 2000 分钟免费额度，每天仅耗时约 1 分钟，完全够用）。
3. **不要**勾选“Add a README file”，直接点击 **Create repository**，复制仓库地址（如 `https://github.com/你的用户名/ai-daily-report.git`）。

### 第 2 步：配置一个大模型 API Key（用于深度中文总结与趋势研判）
打开刚创建的 GitHub 仓库页面，依次点击：
`Settings` -> 左侧 `Secrets and variables` -> `Actions` -> 点击绿色按钮 **`New repository secret`**，添加以下**任意一个**密钥即可（推荐前两个，性价比/免费额度极佳）：

| Secret 名称（填在 Name） | 获取方式与说明（密钥填在 Secret） |
| :--- | :--- |
| **`GEMINI_API_KEY`**（推荐·有免费额度） | 前往 [Google AI Studio](https://aistudio.google.com/apikey) 一键免费创建 API Key |
| **`DEEPSEEK_API_KEY`**（推荐·中文极强） | 前往 [DeepSeek 开放平台](https://platform.deepseek.com/api_keys) 创建 API Key |
| **`DASHSCOPE_API_KEY`** | 阿里云百炼（通义千问 `qwen-plus`）API Key |
| **`OPENAI_API_KEY`** | OpenAI 官方或任意兼容接口 Key |

### 第 3 步：把本地「文稿/每日报告」关联推送到该仓库
把你在第 1 步复制的仓库地址发给 Antigravity 助手（或由我在终端帮你执行连接推送并运行一次 `.automation/setup_mac_sync.sh`），即可立即完成绑定！

绑定完成后，你还可以去 GitHub 仓库的 **`Actions`** 标签页，点击左侧 **`每日 AI 圈早报自动生成`** -> 右侧 **`Run workflow`** 手动点一下测试，1 分钟后就能看到云端自动提交的早报！
