## 一、今日 GitHub AI 工具圈风向速览
今天的 GitHub 飙升榜呈现出几个极其鲜明的技术风向：
1. **Agent Skills 生态大爆发**：围绕 Claude Code、Cursor、Antigravity 等主流 Coding Agent 的垂直领域 Skill（如代码安全漏洞挖掘、学术论文全流程写作、图表设计等）成为绝对主流，开发者正把 Agent 变成全能特种兵。
2. **MCP 与软件原生化（Agent-Native）**：越来越多传统软件和云服务（如 Appwrite、DaVinci Resolve、Firecrawl）原生接入 MCP（Model Context Protocol），让 AI 可以直接在真实生产环境中落地读写。
3. **“轻量化与本地优先”成标配**：无论是极简代码知识图谱、从零训练 64M 大模型的极致性价比方案，还是本地视频切片工具，都强调开箱即用、低 Token 消耗与隐私安全。

* **搭配工具**：`mvanhorn/last30days-skill` + `zhouxiaoka/autoclip` + `firecrawl/firecrawl`
* **实操效果**：
  1. 先用 **`firecrawl`** 抓取各大前沿科技网站的最新硬核长文，再通过 **`last30days-skill`** 跑一遍全网社群（Reddit/HN）的高赞舆情分析，让 AI 帮你精准锁定当前全网最火爆的 AI 创业话题。
