## 一、今日 GitHub AI 工具圈风向速览

* ** Agent 技能包（Skill/Plugin）成为绝对主流**：开发者不再满足于单体 AI，而是为 Claude Code、Cursor、Codex 等 Agent 工具插上领域特定的“技能插槽”，涵盖红蓝对抗、学术写作、架构图绘制及应用上架合规等场景。
* **跨平台协议与多 Agent 协作深化**：MCP（Model Context Protocol）标准广泛落地（如专业剪辑、云资源对接），支持 Agent 跨系统、跨软件（如控制手机或 DaVinci Resolve）直接执行复杂工作流。
* **极简自研与极简 Agent 爆火**：从 3 块钱 2 小时从零训大模型的轻量项目，到仅用百行代码实现在 SWE-bench 上高分通关的 Agent 框架，开发者正极力追求极致的资源效率与架构透明度。
